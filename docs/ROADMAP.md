# Roadmap Consolidado

Data de referencia: **Marco 2026**

Este roadmap consolida dois trilhos:

- `jrvalerio.dev` (portfolio tecnico)
- `EcoVoz` (produto de comunicacao assistiva multimodal)

## Trilho A - Portfolio v2

### Status atual: concluido ate v1.4 base

Evolucao entregue em PRs empilhados:

1. `feat(v2): foundation shell, i18n routing, theme system and analytics base`
2. `feat(v2): information architecture and public documentation pages`
3. `feat(v2): case study engine with typed domain and reading telemetry`
4. `feat(v2): live case-study metrics dashboard with PostHog fallback`

Capacidades ativas:

- App Router v2 com shell dedicado
- Case studies tecnicos
- Architecture + Engineering Decisions (ADR)
- Metrics dashboard
- Command palette + busca global
- Bundle budget gates em CI

### Proximos incrementos (v2.1+)

- i18n completo com deteccao automatica de idioma
- refinamento visual (background e dark mode sofisticado)
- analytics de leitura com heatmaps e section engagement

## Trilho B - EcoVoz

### Posicionamento oficial

> EcoVoz e uma plataforma de comunicacao assistiva multimodal.

### Objetivo do MVP

Permitir que pessoas com dificuldade de comunicacao se expressem por voz,
gestos e AAC em um unico sistema.

### Fases

- **Fase 1 - Estabilizacao da plataforma**: concluida
- **Fase 2 - MVP funcional multimodal**: em execucao
- **Fase 3 - Piloto clinico (Q3 2026)**: planejada
- **Fase 4 - Monetizacao SaaS (Q4 2026)**: planejada
